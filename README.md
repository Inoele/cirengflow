# Invoice Digital — Usaha Rujak Cireng

Front-end prototype berbasis React + Vite + Tailwind CSS. Seluruh data masih dummy dan disimpan di state browser (tidak memakai backend).

## Menjalankan
1. Install Node.js versi LTS.
2. Buka terminal pada folder proyek.
3. Jalankan:
   ```bash
   npm install
   npm run dev
   ```
4. Buka alamat lokal yang muncul di terminal.

## Fitur prototype
- Login demo (akun apa pun yang tidak kosong).
- Dashboard ringkasan.
- Data pelanggan dan produk (tambah data dummy).
- Transaksi sederhana.
- Invoice digital, unduh PNG, dan buka WhatsApp melalui tautan `wa.me`.
- Riwayat transaksi dan status pembayaran.

## Catatan penting WhatsApp
Aplikasi **tidak mengirim pesan atau gambar otomatis**. Tombol WhatsApp membuka WhatsApp dengan teks invoice yang sudah disiapkan. Unduh PNG terlebih dahulu, lalu lampirkan gambar secara manual di WhatsApp.

## Batasan
Belum ada API, database, autentikasi sungguhan, penyimpanan permanen, maupun integrasi pengiriman WhatsApp Business API.
