# UI-GUIDELINE — CirengFlow
**Versi:** 1.0 · **Arah visual:** Modern, futuristik ringan, SaaS, bersih, ramah usaha kuliner.

## 1. Identitas Visual
- **Hijau tua / Forest:** `#123B2B` — sidebar, tombol utama, identitas.
- **Hijau daun / Leaf:** `#2E7650` — aksi, grafik, tautan.
- **Hijau muda / Mint:** `#E8F4EB` — latar ikon, status positif, panel pendukung.
- **Putih:** `#FFFFFF` — kartu, form, invoice.
- **Latar aplikasi:** `#F5F8F5`.
- **Teks utama:** `#18352A`; teks sekunder `#84928A`.

## 2. Tipografi
Gunakan font sistem modern (Inter jika tersedia, fallback sans-serif). Judul tegas dengan ukuran 22–26 px, isi 10–13 px pada dashboard padat, dan invoice memiliki hirarki jelas.

## 3. Prinsip Layout
- Sidebar tetap di desktop, berubah menjadi drawer di mobile.
- Header menampilkan breadcrumb, tanggal, notifikasi, avatar.
- Konten memakai grid kartu dengan jarak konsisten 14–18 px.
- Radius kartu 12–13 px; tombol 8–9 px.
- Gunakan border halus dan bayangan ringan, hindari dekorasi berlebihan.

## 4. Komponen
- **Primary button:** hijau tua, teks putih, ikon di kiri.
- **Secondary action:** latar putih/hijau muda dan border halus.
- **Status:** Lunas hijau; Belum Lunas amber.
- **Search:** input dengan ikon pencarian.
- **Table:** header kecil, baris lega, tindakan lihat invoice.
- **Invoice:** putih, format struk terpisah, identitas usaha, ID, tanggal, pelanggan, item, total, status, ucapan terima kasih.
- **WhatsApp CTA:** hijau WhatsApp, label “Buka WhatsApp” atau “Lanjut ke WhatsApp”.

## 5. Perilaku Responsif
- Desktop: sidebar 252 px dan konten fleksibel.
- Tablet: sidebar lebih ramping, kartu menyesuaikan.
- Mobile: sidebar menjadi drawer; tabel dapat digulir horizontal; form dan invoice ditumpuk vertikal.

## 6. UX dan Aksesibilitas
- Label input selalu terlihat, bukan placeholder saja.
- Tombol memiliki label aksi yang jelas.
- Status tidak dibedakan hanya dengan warna; sertakan teks.
- Beri notifikasi setelah aksi demo.
- Hindari klaim “terkirim” ketika WhatsApp hanya dibuka.
